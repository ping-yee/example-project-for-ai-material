# Triage 標籤

這些技能使用五種標準的分流角色。本文件將這些角色對應至本儲存庫 issue tracker 實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 本儲存庫的標籤    | 用途                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 等待維護者評估此議題       |
| `needs-info`               | `needs-info`      | 等待回報者提供更多資訊     |
| `ready-for-agent`          | `ready-for-agent` | 規格完整，可交由 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要由人類實作             |
| `wontfix`                  | `wontfix`         | 不會進一步處理             |

當技能提到某個角色，例如「套用 AFK-ready triage label」時，請使用表格中對應的標籤字串。

若要配合實際使用的標籤詞彙，請編輯右側欄位。
