# 02: 重複使用並編輯多個標籤

**What to build:** 讓使用者搜尋並重複使用全站既有標籤，在一項任務上選擇最多 10 個既有或新標籤，並於編輯任務時加入或移除標籤。標籤驗證失敗時，使用者應能修正原表單，而不會產生部分寫入。

**Blocked by:** 01「建立並顯示第一個標籤」.

**Status:** ready-for-agent

- [ ] 標籤多選 interface 顯示全站共用的既有標籤，依名稱穩定排序，並支援依名稱搜尋。
- [ ] 「新增標籤」固定顯示於選項頂端，使用者可在同一任務中混用既有與新標籤。
- [ ] 使用者可在一項任務上選擇多個不重複標籤，總數上限為 10 個。
- [ ] 超過 10 個標籤時，整筆任務寫入失敗，表單內容及已選標籤保持可修正狀態。
- [ ] 輸入經頭尾空白或大小寫正規化後已存在的名稱時，顯示「標籤已存在，請從選項中選取」。
- [ ] 重複名稱錯誤不會自動套用既有標籤，也不會建立重複標籤。
- [ ] 編輯任務時，表單以 chip 呈現目前完整標籤集合，並可透過 `×` 加入或移除標籤。
- [ ] 明確提交標籤集合時，以該集合更新任務關聯，包括移除全部標籤；未提交標籤資料的局部更新則保留既有關聯。
- [ ] 成功建立的新標籤會自動成為該任務的已選標籤。
- [ ] 任務寫入、所有新標籤建立及關聯同步為單一原子操作；任一標籤無效時全部回滾。
- [ ] 標籤從最後一項任務移除後仍保留於標籤選項中。
- [ ] 刪除任務只刪除任務及其關聯，不刪除任何標籤。
- [ ] 完整任務清單、單筆任務、搜尋結果與一般篩選結果都回傳並顯示完整標籤集合。
- [ ] HTTP Feature tests 涵蓋混用既有與新標籤、多標籤上限、編輯同步、局部更新、重複名稱、交易回滾及未使用標籤保留。
- [ ] 在瀏覽器完成搜尋標籤、選取多個標籤、建立多個新標籤、編輯移除及錯誤後保留表單的驗收。
