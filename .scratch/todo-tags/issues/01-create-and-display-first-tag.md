# 01: 建立並顯示第一個標籤

**What to build:** 讓使用者在建立任務時選擇「新增標籤」、輸入名稱，並在任務成功儲存後，於任務卡片看見該標籤 chip。建立任務與標籤的可靠寫入基礎，同時讓沒有標籤的既有及新任務清楚呈現為「未加標籤」。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 新增任務表單提供標籤選項，且「新增標籤」固定為清楚可辨識的操作入口。
- [ ] 選擇「新增標籤」後才顯示名稱輸入；取消或未成功儲存任務時，不建立標籤。
- [ ] 任務成功儲存時，新標籤與任務關聯一起建立，回應包含該任務的完整標籤集合。
- [ ] 任務與標籤為可支援多個關聯的模型，且同一任務不能重複關聯同一標籤。
- [ ] 標籤名稱會移除頭尾空白；空名稱與超過 50 個字元的名稱會得到欄位層級驗證錯誤。
- [ ] 標籤名稱允許中文、英文、數字、內部空格及 emoji，長度依使用者可理解的字元計算。
- [ ] 標籤以不分大小寫的正規化名稱保持唯一，資料庫層級也能阻止重複資料。
- [ ] 建立任務、建立標籤及建立關聯為單一原子操作；其中任何一步失敗都不留下部分資料。
- [ ] 任務卡片以安全轉義的純文字 chip 顯示標籤，chip 可在窄版面自動換行。
- [ ] 沒有任何標籤的既有及新任務顯示灰色「未加標籤」chip；系統不建立名為「未加標籤」的實體標籤。
- [ ] 任務清單、單筆任務與新建任務回應使用一致的標籤資料形狀。
- [ ] HTTP Feature tests 從外部 interface 驗證成功、驗證失敗、原子性及讀取結果，不直接斷言 ORM 或關聯表實作。
- [ ] 預設測試命令可以發現並執行本 ticket 新增的 Feature tests。
- [ ] 在瀏覽器完成新增有標籤任務、新增未加標籤任務、chip 顯示及錯誤訊息的驗收。
