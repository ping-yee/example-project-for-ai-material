# 03: 以標籤或未加標籤篩選任務

**What to build:** 讓使用者從任務卡片或標籤篩選選項進入單一標籤篩選，也能找出所有未加標籤的任務，並隨時返回完整清單。標籤篩選結果須延續既有排序能力。

**Blocked by:** 01「建立並顯示第一個標籤」.

**Status:** ready-for-agent

- [ ] 使用者可點擊任務卡片上的一般標籤 chip，查看具有該標籤的任務。
- [ ] 使用者可點擊灰色「未加標籤」chip，查看沒有任何標籤的任務。
- [ ] 標籤篩選選項一次只能選擇一個既有標籤，並提供「全部」與「未加標籤」。
- [ ] 選擇「全部」會離開標籤篩選並重新載入完整任務清單。
- [ ] 標籤篩選結果包含任務的完整標籤集合，並使用與其他任務清單一致的回應形狀。
- [ ] 標籤篩選可以產生正確的單一結果、多筆結果與空結果。
- [ ] 「未加標籤」以零個標籤關聯判定，不依賴任何虛構標籤資料。
- [ ] 標籤篩選支援既有的建立時間、更新時間、標題、優先級、狀態及截止日期排序，以及升序與降序。
- [ ] 標籤 chip 和未加標籤 chip 具有可辨識的點擊狀態與鍵盤可操作性。
- [ ] HTTP Feature tests 從任務查詢 interface 驗證單一標籤、未加標籤、全部、空結果及排序行為。
- [ ] 在瀏覽器完成點擊一般 chip、點擊未加標籤 chip、改選其他標籤、返回全部及保留排序的驗收。
