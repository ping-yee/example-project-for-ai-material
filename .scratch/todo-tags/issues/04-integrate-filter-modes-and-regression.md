# 04: 整合篩選模式並完成回歸驗收

**What to build:** 讓搜尋、一般篩選與標籤篩選成為清楚且互斥的使用模式。使用者切換模式時不會受到上一模式的殘留條件干擾，排序偏好仍會保留，既有任務操作也維持正常。

**Blocked by:** 02「重複使用並編輯多個標籤」、03「以標籤或未加標籤篩選任務」.

**Status:** ready-for-agent

- [ ] 畫面明確顯示目前處於完整清單、搜尋、一般篩選或標籤篩選模式。
- [ ] 啟用標籤篩選時，清除搜尋關鍵字、搜尋結果摘要及一般篩選條件與摘要。
- [ ] 啟用關鍵字搜尋時，清除目前的標籤篩選選項、狀態與摘要。
- [ ] 啟用一般篩選時，清除目前的標籤篩選選項、狀態與摘要。
- [ ] 切換任何篩選模式時保留目前排序欄位與排序方向。
- [ ] 一般篩選仍可同時組合狀態、優先級與日期條件，不因標籤功能而縮減。
- [ ] 標籤篩選不與關鍵字搜尋或一般篩選條件形成隱藏交集。
- [ ] 完整清單、搜尋、一般篩選與標籤篩選中的任務卡片都一致顯示標籤或「未加標籤」。
- [ ] 清除目前模式後，畫面回到完整任務清單，且不留下過期摘要、活躍樣式或輸入值。
- [ ] 建立、編輯、完成、重新開啟及刪除任務在各種清單模式下維持既有外部行為。
- [ ] 使用者提供的任務及標籤文字在所有結果模式中都安全輸出。
- [ ] HTTP Feature regression tests 涵蓋完整清單、搜尋、一般組合篩選、排序及既有任務操作，並確認回應持續包含標籤。
- [ ] 預設測試命令執行所有新舊測試並通過。
- [ ] 依規格完成完整瀏覽器驗收：標籤建立與編輯、chip 顯示、標籤與未加標籤篩選、模式互斥、排序保留及既有任務操作。
